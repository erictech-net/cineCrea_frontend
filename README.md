API Cinéma
Cette API permet de gérer les films, les séances et les réservations d’un cinéma.

Fonctionnalités
Consulter, créer, modifier et supprimer des films.
Consulter, créer, modifier et supprimer des séances.
Consulter et créer des réservations.
Modifier le statut ou supprimer une réservation.
Ressources
L’API propose trois ressources principales : films, séances et réservations. Chaque opération utilise une route dédiée et des schémas de données associés.

La documentation disponible présente les routes et les modèles de données, mais ne détaille pas les champs ni les exemples de requêtes.
